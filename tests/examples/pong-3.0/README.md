# pong-3.0

\[Outdated but still functional\]

The `pong-3.0` example is an evolution of the `pong-2.0` example which was the first to use the **F**lint **I**interop **P**rotocol to enable interoperability with C. This third iteration of Pong now utilizes Flint's compositional approach to create the Pong game.
